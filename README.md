# report-iterate

一套用于自动审查和迭代单篇论文、多篇关联报告的 Codex 技能。调用后由代理组织独立审读、证据核验、修改和复审，并在修改 Word 时核对题注、书签和交叉引用。

- [技能入口](SKILL.md)：说明审读、修改和交付流程，复用用户已确认的要求和自主修改范围。
- [自动审查循环](references/autonomous-review.md)：分配多方独立审查，依据原文和来源处理分歧，统一修改后独立复审，记录收敛与续跑状态。
- [调研与路线探索](references/research-and-ideas.md)：区分启发性例子和明确要求，比较不同机制及其证据、代价和验证条件。
- [Word 执行说明](references/runtime.md)：使用 Python 3.10+ 和 `lxml` 检查 DOCX、执行工单和恢复中断。实际更新目录和域需要 Windows 上的 Word 和 PowerShell 7。
- [项目配置](references/project-profile.md)：可按研究项目维护偏好，另附可选的航天调研配置。

可用以下方式开始一项自动任务。

> 使用 report-iterate 自动审查并迭代指定稿件。按现行项目要求处理，在授权范围内独立检索、比较和修改，每轮完成后自动复审，达到收敛条件后交付成稿、修改对照和检查记录。遇到我已要求先选择的重大调整，保存具体方案并继续其他工作。

需要代理宿主提供模型、子代理和检索等相应能力。Python 批次工具负责文档工单执行与恢复，自动审查由代理依据技能流程完成。

当前版本：v2.2。仓库包含技能源码和使用指引。
